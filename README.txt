PumpMeme ($PumpMeme) — "The Pump Collection", a collectible card binder fan site (Solana / pump.fun)

OPEN: double-click index.html (works offline from file://, no server, no internet needed).

SET THE CA AND X LINK (no rebuild):
  1. Open config.js (in this folder) in any text editor.
  2. Paste the contract address between the quotes after  ca:
     and the full X link (e.g. https://x.com/YourHandle) after  x:
  3. Save, then refresh index.html.
  Every Buy tab, the Chart tab, the CA box, Copy buttons, X tabs, @handle text and the
  "back of the box" facts update automatically. Leave a value as "" and the site shows
  "TBA" / "X link coming soon".

USING THE SITE: a booster pack rips open and deals 7 holo cards into the binder. Tap a card to
pull it up: tilt it with your pointer, tap or press Flip for the stats on the back, swipe or use
← → for the next card, Esc to go back. Inspect all 7 to unlock the secret ultra-rare card.
Tap the pack to deal again.

FILES: config.js (edit me) · index.html · css/style.css · js/app.js (built bundle) ·
js/src/main.js (source; rebuild only if you change code: node build.mjs with esbuild) ·
assets/cards (the 8 official images) · assets/brand (X banner PNG + editable banner-source.html) ·
vendor/fonts.
